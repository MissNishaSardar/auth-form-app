# Auth-Form-App

\*\*

# Description 📝

**
The **Auth-Form-App\*\* serves as functional demonstrating how a frontend application securely capture, validates and manage user information without immediate backend database. Designed with modern structured form validation, asynchronous state updates and local state persistence.

# Tech Stack 🛠️

- **Framework** - [Next.js ](https://nextjs.org/) 16.2 (App Router)
- **Language** - JavaScript with TypeScript
- **UI & Styling** - [Tailwind CSS](https://tailwindcss.com) A utility-first CSS framework combined with [Shadcn ui](https://ui.shadcn.com)
- **Schema Validation** - [Zod](https://zod.dev) paired with [@hookform/resolvers/zod](https://www.npmjs.com/package/@hookform/resolvers)
- **Form primitive** - [React Hook Form](https://react-hook-form.com/) which validate inputs with own rules.
- **Global State** - [Jotai](https://jotai.org) an atomic approach to global React state management.
- **Notification**- React-toastify
- **Theme** - next-themes
- **Icons** - [Lucide React](https://lucide.dev/)
- **Package Manager** - [Bun](https://bun.sh) is a fast, incrementally adoptable all-in-one JavaScript, TypeScript & JSX toolkit.

## Features 🚀

### 1. User Registration

The application allows new users to create an account. It collects essential credentials—typically a name, email address, and a secure password.

### 2. User Authentication

The app dedicated login interface where registered users can authenticate their identity.

### 3. Responsive User Interface (UI)

The application is built with a responsive layout, ensuring that the authentication forms adapt seamlessly across various devices.

### 4. Validation

Schema-driven validation that ensures consistency.
